My LaTeX

This page edits and compiles the LaTeX files stored in your GitHub repository. To let it in, it needs a GitHub access key (a "token") that only works for that one repository.

  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Give it any name and pick an expiry date.
  3. Under Repository access, choose Only select repositories and pick your LaTeX repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write and Actions to Read and write.
  5. Click Generate token, copy it, and paste it below.
